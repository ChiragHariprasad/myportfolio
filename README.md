# Chirag Hariprasad — Portfolio

AI/ML Systems Engineer portfolio: 4 published patents, IEEE Access publication, 19 major projects.

## Stack

- **Frontend:** React 18 + TypeScript + Vite, Tailwind, Framer Motion
- **Rendering:** Per-route prerendering at build time (`vite-prerender-plugin` + `react-dom/server`) — crawlers receive fully rendered HTML with per-route meta/OG/JSON-LD
- **Deployment:** Cloudflare Workers (`wrangler deploy`), SPA fallback for client-only routes

## Development

```bash
npm install
npm run dev        # dev server on :8080
npm run build      # sitemap + og-image + image optimization + tsc + vite build + prerender
npm run deploy     # build + deploy to Cloudflare Workers
npm run check      # typecheck + build + wrangler dry-run
npm run lint
```

## Content

All content lives in `src/react-app/content/**/*.json` (projects, patents, publications, experience, milestones). Add a JSON file there and import it in `src/react-app/data/contentLoader.ts` — pages, search index, timeline, sitemap, and prerender routes pick it up automatically.

## SEO / Discovery

- `public/robots.txt` + generated `public/sitemap.xml` (28 URLs)
- Per-route title/description/canonical/OG/Twitter/JSON-LD injected during prerender (`src/react-app/data/seo.ts`)
- Social preview card: `public/og-image.png` (generated by `scripts/generate-og-image.mjs`)
- Images auto-optimized to WebP by `scripts/optimize-images.mjs`
- Verify rendering: `npm run build && npx vite preview && node scripts/verify-render.mjs`
